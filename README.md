# 手工织锦纹样排版台

直接打开 `index.html` 使用。支持网格绘制、色线统计、撤销重做、本地保存和导出 JSON。

## 色线库存

- 左侧色线库每色可登记**现有格数**。
- 保存方案时按当前画布核算用量：`需用量 = 画布格数 + 断线风险行内该色格数 × 10%`，小数整体向上进位（断线风险行 = 一行内换色次数超过列数 62% 的纬向行）。
- 库存不足时逐色指出“缺哪一色、差多少格”，**保存和库存扣减都不执行**；库存足则保存方案并把库存按需用量扣减。
- 换网格、撤销/重做、应用纹样块或修改库存数字后，缺口都按当前纹样实时重算。
- 旧方案没有库存信息时仍可正常打开，库存按 0 登记，重新填写即可。

## 文件划分

- `js/layout.js`：排版规则——色板、纹样块落格、断线风险行判定、用量核算、重复单元预览（纯计算）。
- `js/archive.js`：方案存档——本地读取/保存、库存校验与扣减、JSON 导出。
- `js/app.js`：页面操作——画布绘制、撤销重做、库存登记与缺口提示等交互。
