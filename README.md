# 手工织锦纹样排版台

直接打开 `index.html` 使用。支持网格绘制、色线统计、撤销重做、本地保存和导出 JSON。

## 色线库与库存核对

- 左栏「色线库」每个色块下方可登记该色**现有库存格数**。
- 右栏「库存核对」按当前画布实时核算各色需求：
  - 一般颜色需求 = 画布用量；
  - 「断线风险」行用到的颜色**多留一成**，小数向上进位（如用 6 格需 7 格，用 10 格需 11 格）；
  - 逐色显示「需 / 存」，不足时标出**缺哪一色、差多少格**。
- 点「保存方案」时再次按当前画布核算：
  - 库存不足 → 明确列出缺口，**保存与库存扣减都不执行**；
  - 库存充足 → 保存方案并按需求量扣减库存（扣减后库存随方案存档）。
- 换网格、撤销/重做、应用纹样块填色后，缺口都随当前纹样自动重算。
- 旧方案没有库存信息时仍可正常打开，缺失库存按 0 处理。

## 文件分工（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `layout.js` | 排版规则：网格创建、纹样块落点、用色统计、断线风险行、加一成核算与缺口计算（纯逻辑，无 DOM） |
| `archive.js` | 方案存档：本地读写、旧方案兼容、保存时的库存校验与扣减、导出 JSON |
| `page.js` | 页面操作：渲染、调色/登记库存/填色/新建/撤销重做等交互，缺口随画布刷新 |

`index.html` 只放结构与样式，按 `layout.js → archive.js → page.js` 的顺序引入。
